## Исследование 1.
# 1. Почему число 1 занимает 4 байта, хотя для его записи достаточно одного байта?
Потому что int в C# всегда занимает 4 байта, даже если значение маленькое - старшие байты просто заполнены нулями.

# 2. Что изменяется в байтовом представлении числа 256?
256 в шестнадцатеричной системе это 0x00000100. Единица переходит из младшего байта во второй байт.

# 3. Почему число 65536 уже требует другого набора байтов?
65536 это 0x00010000 - значение уже не помещается в первые два байте, поэтому единица сдвигается в третий байт.

## Исследование 2.
BitConverter.IsLittleEndian: True
Байты числа 305419896(0x12345678): 78-56-34-12
Система работает в littleEndian, поэтому сначала записывается младший байт: 78, а старший: 12 - последним. Само число при этом не меняется, меняется только порядок байтов в памяти.


## Исследование 3.
# Почему количество символов и количество байтов может отличаться?
В кодировке UTF-8 английские буквы занимают по 1 байту, а русские по  байта. Символ - это один знак текста, а байт - размер его хранения в памяти.

## Исследование 5.
# Почему для обратного преобразования нужно снова указать UTF-8?
Потому что сами по себе байты - это просто набор чисел, и без указания кодировки программа не поймёт, как собрать из них обратно символы.
